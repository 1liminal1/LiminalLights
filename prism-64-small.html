Same Body as the Prism-32, Four Times the Pixels

The Prism-64 uses the same 19 × 21 cm enclosure as the Prism-32 — the difference is what's inside it. Four times the pixel count across the same 12.8 cm face, so animations read smoothly instead of as blocks.

Step up to the Prism-64 Large only if you need it seen from across the room. It's the same 12,288 pixels at 3 mm pitch — 1.5× the display in each direction, 2.25× the area.
